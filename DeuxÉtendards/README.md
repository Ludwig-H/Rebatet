# *Les Deux Étendards*

Ce dossier réunit les travaux sur le roman de Lucien Rebatet, *Les Deux Étendards* (Gallimard, 1951).

- `Les deux étendards (Lucien Rebatet).epub` est le témoin de travail. Toutes les références y renvoient : « XII §124 » désigne le 124e paragraphe du chapitre XII.
- [`IdentificationsLieux/`](IdentificationsLieux/) contient l'identification et la cartographie des lieux lyonnais du roman : 162 lieux, huit dossiers thématiques, des cartes sur fonds de 1950 et un atlas interactif.
