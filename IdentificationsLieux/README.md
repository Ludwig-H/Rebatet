# Identifier les lieux chez Rebatet

Ce dossier rassemble des enquêtes de géographie littéraire fondées sur le texte, les sources historiques et une cartographie explicite de l'incertitude.

## Enquêtes

- **[Lyon dans Les Deux Étendards](Lyon/README.md)** : inventaire du corpus, identifications, dossiers de preuves et cartes.

Chaque enquête distingue le lieu **écrit**, le lieu **historique** et sa **localisation actuelle**. Un nom réel ne suffit pas à garantir qu'un établissement romanesque a existé sous cette enseigne ; une localisation plausible ne vaut pas identification d'une parcelle.

État initial de l'enquête : 23 octobre 2026. Les fichiers originaux du dépôt sont conservés.
